Lo necesario para usar este archivo

Python real: se ejecuta en tu navegador con Pyodide (314.0.7). Usa un navegador actualizado con internet; la primera carga descarga el motor y puede tardar. No hace falta instalar Python ni crear una cuenta.

Como una notebook: las celdas de cada ejercicio comparten sus variables. Shift + Enter ejecuta la celda; Tab inserta cuatro espacios. Si cambias una celda anterior, vuelve a ejecutar el ejercicio. «Detener» reinicia la memoria de Python y conserva tu código.

Guarda tus cambios: se intentan guardar en este navegador. «Guardar mi archivo» descarga un HTML con todas tus celdas editadas; puedes llevarlo a otra PC y volver a ejecutarlas. Los resultados se recalculan. No se garantiza el uso sin conexión.

Ayudas visuales: mostrar_grafo(nodos, aristas, colores, k), mostrar_coloreos(nodos, aristas, soluciones, k) y mostrar_sudoku(pistas, soluciones) dibujan datos calculados por Python. Son funciones incluidas en este archivo; no son parte del lenguaje.

Qué estamos resolviendo: un CSP de satisfacción. Buscamos asignaciones que respeten todas las restricciones; no hay función objetivo. El solucionador aquí es una búsqueda sencilla escrita en Python, no un paquete industrial de CP.
